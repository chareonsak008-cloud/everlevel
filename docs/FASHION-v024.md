# ผลตรวจ v0.24.0

ผ่านการทดสอบ Node: 4 เซ็ต / 12 ชิ้น, ID ไม่ซ้ำ, ตัวสร้างทุกชิ้นใช้ได้, รูปย่อสร้างได้,
สวมและโหลดเซฟกลับได้, ค่าสถานะต่อสู้คงเดิม, โครงตัวละครและแฟชั่นเคลื่อนไหวได้,
ตำแหน่งอนิเมชั่นแฟชั่นที่เวลาเท่ากันตรงกันระหว่าง 30/60 fps,
ไม่สร้างวัตถุหรือระบบอนุภาคเพิ่มทุกเฟรม และล้าง callback เมื่อถอดชุดได้

ทดสอบตัวจัดลำดับสไปรต์จริงโดยใช้ตัววาดจำลอง: ผู้เล่น 30 fps, ตัวอื่น 12 fps,
ผู้เล่นได้ลำดับก่อน และไม่เกินงบวาดเดิมต่อเฟรม
ตรวจ dependency ของ JavaScript ภายใน และทดสอบกิจกรรม/เรทดรอป/การฆ่ามอนสเตอร์เดิมผ่าน

ข้อจำกัด: ไม่มีการทดสอบ WebGL ในเบราว์เซอร์จริง, ไม่ได้วัด FPS บน PC/มือถือ,
ไม่ได้รัน SQL หรือทดสอบบัญชีออนไลน์กับ Supabase ในรอบนี้
โมเดลในตัวอย่างใช้ชิ้นทรงเดียวกับเกม แต่ห้องอนิเมชั่นใช้กล้อง/แสงเรียบง่าย;
ภาพแบบพิกเซลในฉากจริงดูได้ที่ fashion-play.html
