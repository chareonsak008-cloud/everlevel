# ระบบสกิล + เอฟเฟกต์ภาพ (v0.65.2) — โน้ตสำหรับผู้พัฒนาที่จะแก้ต่อ

## ไฟล์ที่เกี่ยวข้อง
- `js/data/skills.js` (คลาส 1) · `js/data/job2Skills.js` (คลาส 2): ข้อมูลสกิล แต่ละสกิลที่ใช้ภาพใหม่มี `vfx: 'nf'` และ `nf: {...}` = สเปกจังหวะ (hits / heals / flashes / texts / pull / dash / lift / sky / speed)
- `js/render/NFSkills.js`: ตัวจัดจังหวะกลาง `fx_nf` อ่าน `sk.nf` แล้วตีดาเมจ/ฮีล/แฟลชตามเวลา (หน่วยวินาที ตั้งแต่กดสกิล)
- `js/render/PixelVfx.js`: ตัวเล่น sprite sheet แบบแผ่นป้ายหันหากล้อง + ตาราง `SKILL_VFX` (สกิล → ชีต, จุดวาง, scale, delay, speed, flip)
- `js/core/Game.js` → `playSkillFx()`: เรียก fx_nf + วางภาพตาม SKILL_VFX (`at:'self'` ตามตัวผู้เล่น · `at:'target'` ที่เท้าเป้า · `side:true` ชีตมุมข้างวางที่เท้าผู้เล่น · `flipToCaster` ลูกพลังพุ่งมาจากฝั่งผู้เล่น · `also:[...]` เล่นหลายชีตพร้อมกัน)
- `assets/vfx/nf_<สกิล>/manifest.json + whole.png`: ชีตที่แปลงแล้ว (anchor = จุดที่วางบนพื้น)

## แก้แล้วใน v0.65.2
1. **เอฟเฟกต์หันตามทิศเป้า** — `PixelVfx.play(..., { aim: { from, to, max } })`
   - `update()` ฉายตำแหน่งผู้ร่ายและเป้าลงจอทุกเฟรม (`aimOf`) แล้วหมุนแผ่นป้ายรอบแกนมองกล้อง ให้แกน +x ของชีตชี้ไปที่เป้า
   - เป้าอยู่ซ้ายจอ = กลับด้านภาพแล้วหมุน (ภาพไม่คว่ำ)
   - มุมเอียงจำกัดด้วย `max`: `side` = 1.1 rad, `flipToCaster` = 1.3 rad ปรับต่อสกิลได้ด้วย `aimMax` ใน SKILL_VFX
   - `to` เป็นฟังก์ชัน → เป้าเดินหนี ภาพหันตาม · เป้าตายแล้วกลับไปใช้ `flip` เดิม
   - ชีตมุมข้างย่อ/ขยายตามระยะบนระนาบจอ (ตัดส่วนที่พุ่งเข้า/ออกจากกล้อง)
2. **ตัวละครค้างหันทิศเก่า** — `SheetChars.update()`
   - ตัวกันสั่นตรงรอยต่อทิศเดิมเปลี่ยนทิศเฉพาะเมื่อมุมใกล้กลางช่อง เป้าที่อยู่ใกล้รอยต่อ (~15% ของทุกมุม) จึงไม่เคยเปลี่ยนท่า
   - ตอนนี้ถ้าทิศเดิมห่างจากมุมจริงเกินครึ่งช่อง +0.06 rad จะเปลี่ยนทันที
   - `playSkillFx` ของสกิลรอบตัว (`target:'self'`) หันหาเป้าที่เลือกอยู่ด้วย
3. **ฮีล/บัฟถึงเพื่อนในปาร์ตี้**
   - `PARTY_SUPPORT` ใน skills.js กำหนดสกิล → รัศมี (ช่อง) แล้วใส่ `sk.party`
   - ฝั่งผู้ร่าย: `Game.supportParty('hl'|'bf', id, lv, amount)` → `Social.sendSupport` ส่ง event `hl` / `bf` ในห้องปาร์ตี้ พร้อมตำแหน่งผู้ร่าย รัศมี และปริมาณฮีล (คำนวณจากสเตตัสผู้ร่าย)
   - ฝั่งรับ: `Social.onSupport` กรองข้อความซ้ำ สมาชิก แมพเดียวกัน และระยะจากตัวเอง → `Game.onPartySupport` ฮีล (ไม่เกิน HP ที่ขาด) หรือใส่บัฟ/โล่ตามเลเวลที่ผู้ร่ายส่งมา
   - ทำงานเฉพาะโหมดออนไลน์ (Supabase) ที่อยู่ในปาร์ตี้

## ยังไม่ได้ทำ / ข้อจำกัด
- ฮีลจากเพื่อนไม่ชุบชีวิตคนที่ตายแล้ว (`REVIVE` ของต้นไม้แห่งชีวิตยังเป็นข้อความ ไม่ได้ชุบชีวิตจริง)
- ผู้เล่นคนอื่นยังไม่เห็นภาพสกิลของกันและกัน (เห็นแค่ท่าโจมตี) — ผู้ร่ายเห็นแสงฮีล/บัฟบนตัวเพื่อนที่โดน
- ปริมาณฮีลมาจากเครื่องผู้ร่าย (ไม่มีเซิร์ฟเวอร์ตรวจ) แต่ฝั่งรับจำกัดไม่เกิน HP ที่ขาด และรับเฉพาะสมาชิกปาร์ตี้

## ทดสอบ
- เปิด `index.html` ผ่าน http server แล้วใช้คอนโซล: `asteria.playSkillFx('<id>', 10, <มอน>)`
- ทุกครั้งที่แก้ให้รัน `python3 scripts/stamp-version.py` หลังเปลี่ยน VERSION ใน js/config.js
- ชุด `tests/*.mjs` ใช้ path แบบ Linux (`URL.pathname`) — บน Windows ให้รันผ่าน WSL
