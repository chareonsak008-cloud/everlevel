# Everlevel v0.12 — คู่มือเปิดเซิร์ฟเวอร์และเล่นบนเบราว์เซอร์

เกมนี้เป็นเว็บล้วน (ไฟล์ HTML/CSS/JS) วางบน **GitHub Pages** ได้ฟรี ส่วนบัญชีผู้เล่น เซฟ และการเห็นกันออนไลน์ใช้ **Supabase** (มีแพ็กเกจฟรี)
ทำตามลำดับ 1 → 7 ใช้เวลาประมาณ 20–30 นาที ไม่ต้องพิมพ์คำสั่งโค้ด ทำผ่านหน้าเว็บทั้งหมด

---

## ขั้นที่ 1 — สร้างโปรเจกต์ Supabase
1. เข้า https://supabase.com → **Sign up**
2. กด **New project** → ตั้งชื่อ เช่น `everlevel` → ตั้ง *Database password* (จดเก็บไว้เอง **ไม่ต้องใส่ในเกม**) → Region เลือก **Singapore**
3. รอประมาณ 2 นาทีจนโปรเจกต์พร้อม

## ขั้นที่ 2 — สร้างตารางในฐานข้อมูล
1. เมนูซ้าย **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase/setup.sql` คัดลอกทั้งหมดไปวาง → กด **Run**
3. ขึ้นว่า *Success* ก็เรียบร้อย (รันซ้ำได้ ไม่ลบข้อมูลเดิม)

## ขั้นที่ 3 — สร้างที่เก็บเกมบน GitHub
1. เข้า https://github.com → **Sign up** (ฟรี) แล้วยืนยันอีเมล
2. มุมขวาบนกด **+** → **New repository**
3. **Repository name**: `everlevel` (ชื่อนี้จะเป็นส่วนหนึ่งของลิงก์เกม)
4. เลือก **Public** (บัญชีฟรีเปิดเว็บได้เฉพาะแบบสาธารณะ — โค้ดเกมบนเว็บใครก็ดูได้อยู่แล้ว ไม่มีข้อมูลลับในไฟล์)
5. **ไม่ต้อง** ติ๊ก *Add a README* → กด **Create repository**

## ขั้นที่ 4 — อัปโหลดไฟล์เกม
1. แตก zip ในคอม แล้ว **เปิดเข้าไปในโฟลเดอร์ `everlevel`** (จะเห็น `index.html`, `css`, `js`, `supabase`, `README-TH.md`)
2. ในหน้า repository ที่เพิ่งสร้าง กดลิงก์ **uploading an existing file**
   (ถ้า repository มีไฟล์แล้ว ให้กด **Add file → Upload files**)
3. **เลือกทุกอย่างข้างในโฟลเดอร์ `everlevel`** แล้วลากไปวางในหน้าเว็บ
   ⚠️ ลาก *ของข้างใน* ไม่ใช่ตัวโฟลเดอร์ `everlevel` — `index.html` ต้องอยู่ชั้นนอกสุดของ repository
4. รอจนรายชื่อไฟล์ขึ้นครบ (ราว 100 ไฟล์ — ถ้าเกิน 100 ให้อัปเป็น 2 รอบ — GitHub อัปได้ครั้งละไม่เกิน 100 ไฟล์ และไฟล์ละไม่เกิน 25 MB)
5. เลื่อนลงล่าง ช่อง Commit message พิมพ์ เช่น `Everlevel v0.16.1` → เลือก **Commit directly to the main branch** → กด **Commit changes**

## ขั้นที่ 5 — เปิดเว็บด้วย GitHub Pages
1. ใน repository กด **Settings** (แถบบน) → เมนูซ้าย **Pages**
2. หัวข้อ *Build and deployment* → **Source** เลือก **Deploy from a branch**
3. **Branch** เลือก `main` และโฟลเดอร์ **/(root)** → กด **Save**
4. รอ 1–5 นาที แล้วรีเฟรชหน้า Pages จะขึ้นลิงก์เกม เช่น
   `https://ชื่อผู้ใช้github.github.io/everlevel/`
5. เปิดลิงก์ดู — ตอนนี้ยังไม่ได้ใส่คีย์ หน้าเกมจะขึ้นว่า "ยังไม่ได้ตั้งค่าเซิร์ฟเวอร์เกม" (แปลว่าวางไฟล์ถูกแล้ว · ตั้งแต่ v0.17.1 เกมเล่นได้แบบออนไลน์เท่านั้น)

## ขั้นที่ 6 — ใส่คีย์ Supabase ลงในเกม (แก้บนหน้าเว็บ GitHub ได้เลย)
1. Supabase → **Project Settings → API** (หรือ *Data API / API Keys*) → คัดลอก **Project URL** และ **anon public key** (หรือ *publishable key*)
2. GitHub → repository → **Add file → Create new file** → ช่องชื่อไฟล์พิมพ์ `js/net/server-config.js`
   (ถ้ามีไฟล์นี้อยู่แล้ว ให้เปิดโฟลเดอร์ `js` → `net` → `server-config.js` → กดรูป **ดินสอ ✏️ (Edit)** แทน)
3. ใส่ 2 บรรทัดนี้ แล้วแทนค่าในเครื่องหมาย `' '` ด้วยของโปรเจกต์คุณ

```js
export const SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

4. กด **Commit changes...** → **Commit changes** แล้วรอ 1–2 นาทีให้เว็บอัปเดต

> ✅ anon/publishable key เป็นคีย์สาธารณะ ใส่ในหน้าเว็บได้ เพราะฐานข้อมูลเปิด Row Level Security ไว้ (แต่ละคนแก้ได้เฉพาะข้อมูลของตัวเอง)
> ⛔ **ห้าม** ใส่ `service_role` / secret key หรือ Database password ลงใน GitHub เด็ดขาด (ทุกคนมองเห็น)

## ขั้นที่ 7 — ตั้งค่าการสมัครสมาชิกใน Supabase
เมนู **Authentication**
- **URL Configuration**
  - **Site URL** = ลิงก์เกมจากขั้นที่ 5 เช่น `https://ชื่อผู้ใช้github.github.io/everlevel/`
  - **Redirect URLs** → Add URL → `https://ชื่อผู้ใช้github.github.io/everlevel/**`
  - จำเป็นสำหรับลิงก์ "ลืมรหัสผ่าน" และลิงก์ยืนยันอีเมล ให้พากลับมาที่เกม
- **ยืนยันอีเมล (Confirm email)** — อยู่ในการตั้งค่าผู้ให้บริการ *Email*
  - เล่นกับเพื่อนไม่กี่คน: **ปิด** ไว้ สมัครแล้วเข้าเกมได้ทันที (ระบบส่งอีเมลฟรีของ Supabase ส่งได้น้อยมากต่อชั่วโมง)
  - เปิดให้คนทั่วไปเล่น: **เปิด** ไว้ และตั้ง SMTP ของตัวเองเพื่อส่งอีเมลได้มากขึ้น

เสร็จแล้ว! เปิดลิงก์เกม → **สมัครสมาชิก** → สร้างตัวละคร → ส่งลิงก์ให้เพื่อน เปิดได้ทุกเบราว์เซอร์ ทั้งคอมและมือถือ 🎉

## อัปเดตเกมเป็นเวอร์ชันใหม่
1. แตก zip เวอร์ชันใหม่
2. ตั้งแต่ v0.13 ใน zip **ไม่มี** ไฟล์ `js/net/server-config.js` แล้ว — ไฟล์เดิมบน GitHub (ที่มีคีย์ของคุณ) จะอยู่เหมือนเดิม ไม่ต้องใส่คีย์ใหม่
3. GitHub → repository → **Add file → Upload files** → ลากของข้างในโฟลเดอร์ไปวาง (ไฟล์ชื่อเดิมจะถูกแทนที่) → **Commit changes**
4. รอ 1–5 นาที ผู้เล่นกดรีเฟรชหน้าเกมก็ได้เวอร์ชันใหม่
- อัปเดตกี่ครั้งก็ไม่เสียโควตา
- ถ้าเวอร์ชันใหม่มีไฟล์เกิน 100 ไฟล์ ให้อัปเป็น 2 รอบ (เช่น รอบแรก `js` รอบสองที่เหลือ)

## มีอะไรใหม่ใน v0.17.1 (กล้องแบบ RO · เล่นออนไลน์อย่างเดียว)
- **กล้องมองจากด้านบนแบบ RO** — ก้ม 60° มุมมองแคบ (ภาพแทบไม่ลึก ตึกไม่เอียง) · ซูมออกได้ไกลขึ้น · ปรับมุมก้มได้ 45°–75°: คอมคลิกขวาลากขึ้นลง หรือ <kbd>PgUp</kbd> <kbd>PgDn</kbd> · มือถือใช้สองนิ้วลากขึ้นลง · จุดปล่อยสกิล จุดโดนตี ป้ายชื่อ ตัวเลขดาเมจ และจุดคลิกเลือกมอนยังตรงกับตัวละคร
- **ภาพพิกเซลอย่างเดียว** — เอาตัวเลือก "กลับเป็น 3 มิติ" ออกจาก ⚙ ตั้งค่าแล้ว
- **ตีมอนออโต้ไม่เดินเก็บของแล้ว** — ของที่ดรอปให้แตะเก็บเอง หรือให้สัตว์เลี้ยงช่วยเก็บ
- **เล่นออนไลน์เท่านั้น** — เอาโหมดออฟไลน์ออกทุกจุด · เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ (หรือรอเกิน 20 วินาที) = ขึ้นแจ้งเตือนพร้อมปุ่ม "ลองใหม่" · ใครเคยเล่นออฟไลน์ไว้ในเครื่อง ย้ายตัวละครขึ้นบัญชีได้ด้วยปุ่ม "ใช้เซฟในเครื่อง" บนช่องตัวละครที่ว่าง
- **แก้บั๊ก** — ข้อความในกล่องแชตบนมือถือเพี้ยนเป็นเศษตัวอักษรเมื่อขยายกล่อง (บรรทัดถูกบีบ) · เลื่อนอ่านแชตย้อนหลังได้ครบ · ระยะซูมจากเซฟเก่าทำให้ภาพพิกเซลไม่คม
- ไม่มีไฟล์ใหม่ (แก้ไฟล์เดิมใน `index.html`, `css/`, `js/`) · ไม่ต้องรัน SQL เพิ่ม · ระบบออนไลน์ไม่เปลี่ยน ผู้เล่น v0.17 กับ v0.17.1 ยังเห็นกัน แต่แนะนำให้ทุกคนรีเฟรชหน้าเกม

## มีอะไรใหม่ใน v0.17 (ภาพแบบพิกเซลอาร์ตทั้งเกม)
- **ตัวละคร** — ผู้เล่นและ NPC ออกแบบใหม่ สัดส่วนอนิเมะ (สูงราว 4 หัว) ชุดอาชีพละเอียดขึ้น แสดงเป็นสไปรต์พิกเซลแบบเกม RO บนฉาก 3 มิติ หมุนกล้องได้เหมือนเดิม
- **มอนสเตอร์ทั้ง 17 แบบ** ออกแบบใหม่ทั้งหมด
- **สัตว์เลี้ยงช่วยเก็บของ 12 ตัว + ผู้ติดตามแฟชั่น 19 ตัว** ออกแบบใหม่ ตัวใหญ่ขึ้น หน้าตาชัดขึ้น
- **ฉากทุกแผนที่** — วาดเป็นพิกเซลความละเอียดเดียวกับตัวละคร (1 ช่องแผนที่ = 48 พิกเซล) มีเส้นขอบเข้ม · พื้นลายพิกเซล (หญ้า ดิน หินปู ลานเมือง หิมะ) · น้ำ น้ำแข็ง และลาวาแบบพิกเซล · กล้องล็อกตามตารางพิกเซล ภาพไม่สั่นตอนเดิน
- **ต้นไม้ หิน พุ่มไม้ หญ้า ดอกไม้** ชุดใหม่ (ต้นไม้กลม สน สนหิมะ ต้นไม้ตายที่มีรอยแตกเรืองไฟ)
- **สิ่งปลูกสร้าง** — บ้าน แผงตลาด ลัง ถัง กำแพง หอคอย สะพานไม้ เต็นท์ กะโหลกมังกร ใช้ลายพิกเซลและแสงเงาเป็นขั้นแบบการ์ตูน
- **สกิลทุกอาชีพ** — เอฟเฟกต์เป็นพิกเซล (แสงฟุ้งเป็นลายจุด ไม่เบลอ) · ไอคอนสกิล 32 อันวาดใหม่เป็นพิกเซล 32×32 · รูปย่อชุดแฟชั่นและสัตว์เลี้ยงเป็นพิกเซลด้วย
- **การซูม** เลื่อนเป็นขั้น เพื่อให้พิกเซลคมทุกระดับ
- **สลับกลับได้** — ⚙ ตั้งค่า → กราฟิก → "ภาพแบบพิกเซลอาร์ต" (เปิดเป็นค่าเริ่มต้น) · ปิด = 3 มิติแบบเดิมทั้งหมด · สลับระหว่างเล่น แผนที่จะโหลดใหม่ที่ตำแหน่งเดิม
- มีไฟล์ใหม่ 6 ไฟล์ใน `js/render/` (CostumePets, PixelArt, PixelFlora, PixelGround, PixelSprites, PixelTextures) — ต้องอัปโหลดด้วย ไม่อย่างนั้นเกมจะเปิดไม่ขึ้น
- ⚠ ยังไม่ได้ทดสอบบนมือถือจริง ถ้าเครื่องไหนกระตุก ให้ลดคุณภาพที่ ⚙ ตั้งค่า → กราฟิก หรือปิดโหมดพิกเซล
- ระบบออนไลน์ไม่เปลี่ยน ผู้เล่น v0.16.1 กับ v0.17 ยังเห็นกันในแผนที่ แต่แนะนำให้ทุกคนรีเฟรชหน้าเกมหลังอัปเดต
- ไม่ต้องรัน SQL เพิ่มใน v0.17

## มีอะไรใหม่ใน v0.16.1 (แก้การเห็นผู้เล่นคนอื่น)
อาการที่แก้: เห็นผู้เล่นคนอื่นแล้วหายไป · พิมพ์แชตแล้วอีกฝั่งไม่เห็น · ตัวละครคนอื่นกระตุก · อยู่แมพเดียวกันแต่ไม่เห็นกัน
- **เห็นกันเสถียรขึ้น** — ระบบออนไลน์ถูกเขียนใหม่: ห้องของแต่ละแผนที่ใช้ข้อความล้วน (ไม่พึ่งรายชื่อ presence ที่หล่นง่าย) · ชื่อ/เลเวล/อาชีพมาจากห้องรวมแยกต่างหาก · คนใหม่เข้าแมพจะขอ "สวัสดี" แล้วทุกคนส่งข้อมูลตัวเองให้ภายใน ~0.5 วินาที
- **แก้บั๊กวาร์ปเร็ว ๆ** — วาร์ปไปแมพอื่นแล้วกลับมาทันที เคยทำให้ช่องค้างจนไม่เห็นใครอีกเลย (แก้แล้ว)
- **ต่อใหม่เอง** — ถ้าเน็ตหลุด/สลับแอปไปนาน/เซิร์ฟเวอร์ตัดช่อง เกมสร้างช่องใหม่ให้เองและกลับมาเห็นกันภายใน ~8 วินาที (เดิมต้องรีเฟรชหน้า) · ถ้าหลุดเกิน 12 วินาทีมีข้อความเตือน และแจ้งเมื่อกลับมาเชื่อมต่อแล้ว
- **แชตไม่หาย** — ข้อความแชต/โทรโข่งส่งตรงถึงทุกคนในแมพ (ไม่ต้องรอรายชื่อ) ส่งพลาดจะลองใหม่ให้ถึง 5 ครั้ง และกันข้อความซ้ำ
- **ตัวละครคนอื่นเดินลื่น** — ผู้ส่งบอก "ตำแหน่ง + ความเร็ว" ตัวละครที่เห็นจึงเดินต่อเองระหว่างรอข้อมูลใหม่ (เดิมกระตุกหยุด-เดินเพราะรอข้อมูลทีละก้อน) · เวลาวาร์ปในแมพจะย้ายตามทันที ไม่ไถลข้ามจอ
- **ใช้โควตา Supabase น้อยลงมาก** — ยืนอยู่เฉย ๆ แทบไม่ส่งอะไร · เดินตรงส่งเป็นระยะห่าง ๆ · เทสต์จำลองคนเดียวเดิน 30 วินาที ส่งข้อความ 109 → 4 ครั้ง
- ⚠ แพ็กเกจฟรีของ Supabase จำกัด **100 ข้อความ/วินาที และ 200 การเชื่อมต่อพร้อมกันต่อโปรเจกต์** — ถ้าในแมพเดียวกันมีคนเดินพร้อมกันเกินประมาณ 10 คน คนที่เห็นอาจกระตุกบ้าง (ยืนเฉย ๆ ไม่นับ) ถ้าคนเล่นเยอะกว่านี้ค่อยอัปเกรดเป็น Pro

  — ถ้ายังไม่ได้สวมแฟชั่น/ยังไม่มีสัตว์เลี้ยงออกมา เกมจะสวมชุดและเรียกสัตว์เลี้ยงให้ทันที

- ของขวัญต้อนรับใช้ได้ทันทีโดยไม่ต้องตั้งค่าอะไร · ส่วน **จดหมายจากแอดมินต้องตั้งค่า Supabase เพิ่ม 1 ครั้ง** (ด้านล่าง)

## ตั้งค่าระบบจดหมายแจกของ (ทำครั้งเดียว · v0.15)
1. Supabase → **SQL Editor** → **New query** → เปิดไฟล์ `supabase/mail.sql` คัดลอกทั้งหมดมาวาง → กด **Run**
   (ติดตั้งเกมใหม่ตั้งแต่ต้น ใช้ `setup.sql` ไฟล์เดียวก็มีระบบจดหมายแล้ว)
2. **ตั้งตัวเองเป็นแอดมิน** — New query อีกอัน วางบรรทัดนี้ แก้อีเมลเป็นอีเมลที่ใช้สมัครเล่นเกม แล้วกด **Run**
```sql
insert into public.admins (user_id, note) select id, 'เจ้าของเกม' from auth.users where email = 'อีเมลที่ใช้สมัครเกม' on conflict (user_id) do nothing;
```
3. เข้าเกมใหม่ → กด **M** (หรือ ☰ → 📬) → จะมีปุ่ม **✉ ส่งจดหมาย (GM)** มุมขวาบนของหน้าต่าง
4. กรอกหัวข้อ · พิมพ์ชื่อไอเทมแล้วกด **เพิ่ม** · ใส่ Zeny · ติ๊กชุดแฟชั่น/สัตว์เลี้ยงที่ให้เลือก (ถ้ามี) → กด **ส่งจดหมาย** 2 ครั้ง (ครั้งที่สองคือยืนยัน)
- ผู้เล่นเห็นจดหมายภายใน 3 นาที หรือทันทีเมื่อเปิดกล่องจดหมาย · คนที่สมัครทีหลังก็รับได้จนจดหมายหมดอายุ
- สิทธิ์แอดมินตรวจที่ฐานข้อมูล ผู้เล่นคนอื่นส่งจดหมายเองไม่ได้ · เพิ่ม/ถอดแอดมินได้ที่ Supabase → **Table Editor** → `admins`
- ⛔ เหมือนเดิม: ไม่ต้องใช้ `service_role` key ใด ๆ — อย่าใส่ลงไฟล์เกมหรือ GitHub

## ดูข้อมูลผู้เล่น / แก้ปัญหา
- เปิดลิงก์แล้วขึ้น **404** → ตรวจว่า `index.html` อยู่ชั้นนอกสุดของ repository (ไม่ได้อยู่ในโฟลเดอร์ `everlevel` ซ้อนอีกชั้น) และขั้นที่ 5 เลือก `main` + `/(root)` แล้ว
- เปิดเกมแล้วขึ้น "เชื่อมต่อเซิร์ฟเวอร์เกมไม่ได้" → ตรวจ URL/คีย์ใน `server-config.js` (ต้องอยู่ในเครื่องหมาย `' '`), ตรวจว่าโปรเจกต์ Supabase ไม่ได้ถูกพัก
- กดลิงก์ลืมรหัสผ่านในอีเมลแล้วไปหน้าอื่น → ตรวจ Site URL / Redirect URLs ในขั้นที่ 7
- สมัครไม่ได้ "ทำรายการบ่อยเกินไป" → ระบบอีเมลฟรีเต็มโควตา: ปิด Confirm email หรือรอสักพัก
- แก้ไฟล์แล้วเกมยังเหมือนเดิม → รอ 1–5 นาที แล้วกดรีเฟรช (มือถือ: ปิดแท็บแล้วเปิดใหม่)
- ดูข้อมูลผู้เล่น: Supabase → **Table Editor** → `characters` (ตัวละคร + เซฟ), `accounts` (คลังเก็บของ) · **Authentication → Users** → ดู/ลบบัญชี
