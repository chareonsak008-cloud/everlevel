# Everlevel v0.21.0 — อาวุธ ชุด และเครื่องประดับใหม่

เกมเต็มต่อจาก v0.20 เนื้อหาเลเวล 60–99 รวมอยู่ครบ ไม่ต้องลง ZIP สองชุด

## เปิดตัวอย่าง

- `equipment.html`: ห้องลองสวม เลือก 4 อาชีพ 7 ช่วงเลเวล 7 เกรด ลากหมุนตัวละคร เลือกยืน เดิน โจมตี/ร่ายเวท และแตะไอเทมจริงในคลังเพื่อดูบนตัวละคร
- `preview.html`: ทดลองเล่นเนื้อหา Lv.60–99 ด้วยตัวละครแยกจากเซฟจริง
- `index.html`: เกมปกติ ใช้เซฟและการเชื่อมต่อเดิม

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เช่น `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/equipment.html` การแตะ HTML จากแอป Files โดยตรงอาจไม่โหลด ES modules

## ดีไซน์ใหม่

อุปกรณ์จริงครบ 96 ชิ้น ใช้รูปทรงเดียวกันระหว่างไอคอนและโมเดลที่สวม: มีด ดาบ ไม้เท้า ธนู คทา ชุด หมวก โล่ ผ้าคลุม รองเท้า เครื่องประดับ

ธีมตามเลเวล: 1–9 นักเดินทาง / 10–24 พงไพร / 25–39 ธารน้ำแข็ง / 40–59 เตาหลอมเพลิง / 60–74 อาณาจักรรูน / 75–89 วิญญาณจันทรา / 90–99 จันทร์โลหิต

เกรดขาว เขียว ฟ้า ม่วง ส้ม ทอง แดง เพิ่มการ์ดดาบ ครีบโลหะ ผลึก ตราสัญลักษณ์ ขอบทอง และชิ้นตกแต่งตามเกรด วัสดุผลึกเรืองแสงแบบ emissive ไม่ใช้ bloom หรืออนุภาคหนัก

ห้องลองสวมแสดงตัวอย่างดีไซน์ครบทุกคู่เลเวล/เกรด ไม่ได้เพิ่มไอเทมดรอปใหม่ทุกคู่ อุปกรณ์จริงแต่ละชิ้นยังใช้เลเวลและเกรดเดิม

## อัปเดตไฟล์

ชุดนี้เป็นซอร์สเต็มพร้อมโครงสร้างสำหรับ GitHub Pages ต้องแตก ZIP ก่อนอัปไฟล์ข้างในที่มี `index.html`, `js`, `css`, `assets`, `vendor` ไม่ใช่อัป ZIP เป็นหน้าเกม ในงานนี้ยังไม่ได้อัป GitHub ของผู้ใช้

รักษา `js/net/server-config.js` ที่ตั้งค่าไว้บนเว็บเดิมเองหากมี ชุดนี้ไม่รวมไฟล์ตั้งค่าส่วนตัว ค่าสเตตัส ราคา ดรอป ID ไอเทม และเซฟเก่าไม่เปลี่ยนจาก v0.20

## ขอบเขต

งานนี้ต่อจากซอร์ส v0.20 ที่ผู้ใช้ให้มา ไม่ได้รวมตัวละครวาดใหม่จากสาขา v0.19 แยกต่างหาก การเปลี่ยนอุปกรณ์ไม่ใช่การแก้ pipeline เดิน/สไปรต์ทั้งหมด

ดู `TEST_REPORT.md` และตัวอย่างโมเดลจริงใน `docs/` ยังไม่ได้ตรวจ FPS บนอุปกรณ์จริง
