# อัปเดตปัจจุบัน v0.26.0 — ของมือรองตามอาชีพ + ธนูลื่นขึ้น + เอฟเฟกต์แฟชั่น

- **ช่องมือรองตามอาชีพ** (ช่อง "โล่" เดิมเปลี่ยนชื่อเป็น "มือรอง" เซฟเดิมใช้ได้)
  - สายดาบ: โล่ (โล่ใช้ได้เฉพาะสายดาบและเด็กฝึกหัดแล้ว)
  - สายธนู: **ซองลูกธนู** สะพายหลัง (ATK · DEX · Ranged DMG · CRIT DMG)
  - สายฮีล: **สมุดเวท** ลอยข้างไหล่ (MDEF · INT · Heal Power · ฟื้น SP)
  - สายเวท: **ลูกแก้วเวท** ลอยข้างตัว (MATK · INT · Max SP · ร่ายเร็ว)
  - มี 7 ขั้นต่ออาชีพ (Lv.1 → 95 ขาว → แดง) ดรอปจากมอนตามช่วงเลเวล · ร้านการ์ธขายชิ้นเริ่มต้น · เปลี่ยนอาชีพได้ชิ้นเริ่มต้นฟรี
  - เซฟเก่าที่สายธนู/เวท/ฮีลสวมโล่อยู่ → โล่กลับเข้ากระเป๋าอัตโนมัติ · ชิ้นจันทร์โลหิตนับเป็นชิ้นเซ็ตเหมือนโล่จันทร์โลหิต
- **ท่าธนูลื่นขึ้น**: ทุกท่าเปลี่ยนแบบค่อย ๆ ไล่ (ไม่กระตุก) · ยืนถือคันธนูตั้งตรง · หลังยิงจะค้างท่าเล็งต่อระหว่างสู้ แล้วค่อยลดลง · หน้าไม้ก็เช่นกัน · ท่าอาวุธอื่นก็นุ่มขึ้นทุกอาชีพ
- **แก้แฟชั่นไม่ขึ้นรูป**: ปีกโฮโลแกรม วงเวทย์หลัง ปีกห้วงจักรวาล ฯลฯ ที่มีลวดลายเท็กซ์เจอร์ เดิมถูกซ่อนในโหมดพิกเซล — แสดงครบแล้ว
- **ของประดับหลังชิ้นเล็ก** (ตุ๊กตาหมี ถุงของขวัญ ฯลฯ) เดิมถูกตัวบังมองไม่เห็นจากด้านหน้า → ขยายและให้โผล่พ้นไหล่ · **ปีกโฮโลแกรม** เห็นชัดขึ้นบนพื้นสว่าง
- **เอฟเฟกต์แฟชั่นเยอะขึ้น**: อนุภาคทุกชิ้นมากขึ้น ~1.8 เท่าและใหญ่ขึ้น · ออร่าถี่ขึ้นอีก 1.5 เท่า + วงแสงที่พื้นเต้นตามจังหวะทุกออร่า
- ไม่ต้องรัน SQL เพิ่ม

## ดีไซน์ใหม่

อุปกรณ์จริงครบ 96 ชิ้น ใช้รูปทรงเดียวกันระหว่างไอคอนและโมเดลที่สวม: มีด ดาบ ไม้เท้า ธนู คทา ชุด หมวก โล่ ผ้าคลุม รองเท้า เครื่องประดับ

ธีมตามเลเวล: 1–9 นักเดินทาง / 10–24 พงไพร / 25–39 ธารน้ำแข็ง / 40–59 เตาหลอมเพลิง / 60–74 อาณาจักรรูน / 75–89 วิญญาณจันทรา / 90–99 จันทร์โลหิต

เกรดขาว เขียว ฟ้า ม่วง ส้ม ทอง แดง เพิ่มการ์ดดาบ ครีบโลหะ ผลึก ตราสัญลักษณ์ ขอบทอง และชิ้นตกแต่งตามเกรด วัสดุผลึกเรืองแสงแบบ emissive ไม่ใช้ bloom หรืออนุภาคหนัก

ห้องลองสวมแสดงตัวอย่างดีไซน์ครบทุกคู่เลเวล/เกรด ไม่ได้เพิ่มไอเทมดรอปใหม่ทุกคู่ อุปกรณ์จริงแต่ละชิ้นยังใช้เลเวลและเกรดเดิม

## อัปเดตไฟล์

ชุดนี้เป็นซอร์สเต็มพร้อมโครงสร้างสำหรับ GitHub Pages ต้องแตก ZIP ก่อนอัปไฟล์ข้างในที่มี `index.html`, `js`, `css`, `assets`, `vendor` ไม่ใช่อัป ZIP เป็นหน้าเกม ในงานนี้ยังไม่ได้อัป GitHub ของผู้ใช้

รักษา `js/net/server-config.js` ที่ตั้งค่าไว้บนเว็บเดิมเองหากมี ชุดนี้ไม่รวมไฟล์ตั้งค่าส่วนตัว ค่าสเตตัส ราคา ดรอป ID ไอเทม และเซฟเก่าไม่เปลี่ยนจาก v0.20
